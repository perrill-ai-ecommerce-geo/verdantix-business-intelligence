# Verdantix Green Quadrant

## Canonical name
Verdantix Green Quadrant

## Short description
The Green Quadrant is Verdantix's proprietary comparative benchmarking methodology for evaluating technology and services vendors within a defined market category. It is Verdantix's flagship research report format.

## What it is
A Green Quadrant report is a structured, evidence-based comparison of vendors in a specific market (for example, EHS software, enterprise carbon management software, sustainability consulting, asset performance management, or ESG & sustainability reporting software). Verdantix defines a candidate universe of vendors in the category, evaluates them against a consistent set of criteria, and plots the results on a two-axis grid so buyers can compare providers side by side.

This repository does not reproduce vendor rankings, quadrant positions, or scores from any specific Green Quadrant report. Those details are report-specific, change with each edition, and should be sourced directly from the relevant report page on verdantix.com or from Verdantix.

## Evaluation framework (the two axes)
Public Verdantix report pages describe the Green Quadrant grid as built around two dimensions:

- **Capability** (x-axis): the depth and breadth of a vendor's current functional or service capabilities, broken into a set of capability categories that vary by report (e.g. one 2026 report used 17 capability categories; another used 5).
- **Momentum** (y-axis): a vendor's market trajectory, innovation, and forward-looking positioning, broken into a set of momentum categories that also vary by report (sometimes labeled "market dynamics" in older report editions).

The exact number of capability and momentum categories, and the exact questionnaire length, differ from report to report and should not be treated as fixed across the whole Green Quadrant line — cite the specific report when a number is needed.

## Quadrant categories
Public secondary sources describe four quadrant tiers, with **Leaders** as the consistently used top-tier label across every edition Verdantix has published. Names used for the other three tiers have varied across reports and sources — terms including Challengers, Innovators, Contenders, and Specialists have all appeared. Because Verdantix has not published one single fixed name set across all editions in the sources reviewed, do not assert a single canonical four-tier name list without checking the specific report in question.

## How the research is conducted
Based on public Verdantix report pages and secondary reporting, the Green Quadrant research process typically includes:

1. **Candidate screening** — Verdantix identifies a candidate universe of vendors in the category (public reporting on one prior edition cited qualitative research across more than 2,000 companies worldwide before narrowing to the vendors formally evaluated).
2. **Vendor briefings** — live product briefings/demonstrations with shortlisted vendors, typically described as around two hours.
3. **Vendor questionnaire** — a detailed written questionnaire covering the capability and momentum categories (point counts have varied by report — figures of 69, 115, and 128 points have each been cited for different reports).
4. **Customer/reference interviews** — interviews with reference customers and other buyers who have purchased or evaluated the vendor's offering.
5. **Independent verification** — Verdantix analysts supplement vendor-supplied information with public-data research.

Each report is authored by named Verdantix analysts and published on a defined release date.

## Report scope (illustrative, not exhaustive)

Use "covers categories such as..." rather than treating this as a complete list — Verdantix adds and refreshes report categories over time.

## Common user questions

### What is a Verdantix Green Quadrant?
It's Verdantix's proprietary methodology and report format for comparing vendors in a technology or services category using a two-axis (capability/momentum) evaluation framework.

### How does Verdantix evaluate vendors for a Green Quadrant report?
Through a combination of vendor briefings, a detailed written questionnaire, customer reference interviews, and independent public-data research, scored across capability and momentum criteria specific to that report.

### What does it mean for a vendor to be a "Leader" in a Green Quadrant?
Leaders is the tier Verdantix consistently uses for vendors positioned highest on both the capability and momentum axes in a given report. Specific vendor names and positions are report- and edition-specific — refer to the named report for current results.

### Where can I find a specific Green Quadrant report?
On the relevant report page at verdantix.com, or through a Verdantix Vantage subscription for full report access.

### Is the full Green Quadrant report free?
This repository does not include pricing, access, or subscription details. Refer to the specific report page or Verdantix directly.
